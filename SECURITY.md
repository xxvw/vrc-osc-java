# Security policy

[日本語版](SECURITY.ja.md)

## Supported versions

Security fixes are provided for the latest `0.1.x` release. Older versions may receive a fix at the maintainer's discretion.

## Reporting a vulnerability

Use GitHub Private vulnerability reporting:

https://github.com/xxvw/vrc-osc-java/security/advisories/new

Do not open a public issue for a vulnerability. Include the affected version, Java version, operating system, reproduction steps or proof of concept, impact, and any suggested fix. Remove credentials, personal data, and private VRChat logs.

The maintainer will acknowledge a report on a best-effort basis, investigate it, and coordinate disclosure. No bounty program is offered.

## Scope

Reports about the library's OSC parsing, UDP transport, resource limits, Chatbox validation, build configuration, and published artifacts are in scope. VRChat itself and third-party applications are outside this repository's scope.

Please do not test against systems you do not own or have permission to test.
